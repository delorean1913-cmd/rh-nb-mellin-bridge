# Contributing

Contributions should identify their layer before making any mathematical claim.

## Required label

Every contribution must be labeled as one of:

1. `finite theorem artifact`
2. `finite diagnostic`
3. `conjectural L2_eff bridge`
4. `conditional BD/NB implication`
5. `obstruction or counterexample`

## Proof-task format

A proof task must state:

- target theorem;
- assumptions;
- dependencies;
- proof route;
- failure mode;
- expected output.

## Numerical-task format

A numerical task must state:

- exact object computed;
- precision or interval method;
- reproducibility instructions;
- certificate format, if any;
- why the task is relevant to the analytic bridge.

More values of \(N\) by themselves are low priority unless they produce a certificate, test a specific analytic lemma, or expose an obstruction.
