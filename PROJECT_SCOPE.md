# Project scope

## In scope

This repository is for:

- finite theorem artifacts;
- finite diagnostics that test one explicit analytic candidate;
- exact or interval-certified Gram and Cholesky artifacts;
- proof tasks for the conjectural \(L^2_{\rm eff}\) bridge;
- explicit counterexamples or obstruction lemmas;
- clean manuscript drafts that preserve the three-layer separation.

## Out of scope

This repository is not for:

- claims of a final RH proof;
- tuned Hermitian operator claims based only on empirical spectral matching;
- GUE or zero-spacing diagnostics presented as proof-level evidence;
- copyrighted books or journal PDFs;
- private correspondence;
- secrets, tokens, passwords, or API keys.

## Naming rule

Use names such as:

```text
finite_diagnostic
finite_theorem_artifact
conjectural_L2_eff_bridge
conditional_BD_NB_implication
```

Avoid names such as:

```text
final_RH_proof
operator_proof
verified_RH_solution
```

unless a complete accepted proof actually exists.
